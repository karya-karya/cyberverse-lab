# CyberVerse Lab

A hands-on cybersecurity learning and engineering laboratory.

## Mission

Build practical skills in networking, system administration, offensive security, defensive security, digital forensics, and emerging security technologies through documented, repeatable labs.

## Core Laboratory

The main project is a simulated corporate environment that will gradually include:

- Network segmentation with VLANs and routing
- Windows and Linux systems
- Active Directory, DNS, and DHCP
- Firewall and network traffic monitoring
- Security testing in an isolated environment
- SIEM, detection engineering, and incident response
- Digital forensics and Purple Team exercises

## Learning Areas

1. Networking
2. Linux and Windows Administration
3. Enterprise Infrastructure
4. Offensive Security
5. SOC and Blue Team
6. Digital Forensics and Incident Response (DFIR)
7. Purple Team Operations
8. OT, Telecommunications, and Hardware Security
9. AI and Quantum Security Fundamentals

## Documentation Standards

Each lab should document:

- Objective
- Environment and tools
- Setup steps
- Commands and configurations
- Results and screenshots
- Security implications
- Lessons learned
- References

## Responsible Use

All security testing will be performed on systems I own or have explicit permission to test. Credentials, secrets, and sensitive personal or organizational data will not be committed to this repository.
